# 映澈 Yingche

Windows 本地视频播放器与 Edge 视频增强扩展。GPUPixel 负责肤质处理，Deep-Live-Cam 开源核心负责本地换脸，独立追踪负责脸型、妆容与运动跟随。

[下载 v0.4.1 预发布](https://github.com/daoguang1012/yingche/releases/tag/v0.4.1) · [Edge 使用说明](EDGE使用说明.md) · [模型与下载](MODELS.md) · [实测记录](VALIDATION.md)

## 安装

1. 下载 `Yingche-v0.4.1-windows-x64.zip`，完整解压到可写目录。
2. 首次使用先运行 `DownloadModels.cmd`。选 1 安装人脸追踪模型；选 2 同时安装换脸所需模型。下载后校验 SHA256，可重复运行。
3. 双击 `Yingche.exe`，Ctrl+O 或拖入视频。

**公开包不附带模型，也不会在打开播放器时自动联网下载。** 无模型时可播放视频，GPUPixel 肤质滤镜可用；人脸定位、脸型和换脸需要先安装对应模型。首次下载后重启播放器。无需安装 Python、Qt 或 CUDA；优先使用 DirectML，性能取决于显卡。

## 功能

- 常见本地视频格式，时间线、逐帧、播放列表、字幕、音轨、截图、全屏、位置记忆及 0.25～4 倍速。
- GPUPixel 1.3 肤质处理；瘦脸、大眼、鼻翼、下巴、唇色等宽范围参数。
- 本机源照片换脸，支持最大脸、指定位置和多人目标。
- Edge 扩展直接增强网页视频，并提供播放、进度、倍速控制；需要播放器保持 Edge 本地连接。
- 视频和照片均在本机处理，不上传云端。

## 当前限制

这是预发布版本，尚未完成各大视频网站或亚洲审美主观验收。快速转头、遮挡、大侧脸可能掉脸，不能保证零闪动或人物交叉后的永久身份锁定。INSwapper 底层为 128 分辨率。当前 SDR 8-bit，内部输出最多 2560×1440；4K60/HDR 保真未验收。跨域视频可能需要用户主动捕获；DRM 不支持。
