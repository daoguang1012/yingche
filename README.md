# 映澈 Yingche 0.6.0

Windows 本地视频播放器与 Edge 视频增强扩展。桌面端沿用 libmpv + Qt + GPUPixel，重点改进自然美颜稳定性、单片参数记忆和双屏操作。

[下载 v0.6.0 预发布](https://github.com/daoguang1012/yingche/releases/tag/v0.6.0) · [使用与验收](0.6.0使用与验收.md) · [Edge 使用说明](EDGE使用说明.md) · [模型安装](MODELS.md) · [实测记录](VALIDATION.md)

## 安装

1. 下载 `Yingche-v0.6.0-windows-x64.zip`，完整解压到可写目录。升级时使用独立文件夹，先保留旧版本。
2. 首次使用运行 `DownloadModels.cmd`，选 1 安装约 4 MB 的人脸追踪模型。选 2 额外安装实验性换脸模型。下载均检查长度和 SHA256。
3. 双击 `Yingche.exe`，Ctrl+O 或拖入本地视频。无需另装 Python、Qt 或 CUDA。

桌面人脸模型不在公开包内，也不会随播放器启动自动下载。没有模型仍能播放视频；0.6.0 桌面局部美颜需要可靠的人脸分析，缺失模型时回原画。已有模型可以复制到新目录的 `models`；旧 `data` 先备份，再复制以迁移设置。`settings-v2.json` 与旧 `settings.json` 分开保存。

## 0.6.0 功能

- 局部皮肤混合、运动对齐的遮罩平滑与渐入渐出；跟踪过期、无人脸或分析失败时回原画。
- 自然、柔和、暗光三个温和预设；单片设置、全局默认、临时预览三个范围。暗光预设不能恢复缺失细节。
- 按住 R 看原片，松开恢复；C 左右同帧对照；F10 将控制和播放画面分到两块屏幕，沿用同一视频与时钟。
- 常见视频格式、时间线、逐帧、播放列表、字幕、音轨、截图、全屏、位置记忆及 0.25～4 倍速。
- 换脸与网页 AI 补帧均默认关闭，保留手动启用和原有参数。旧扩展首次升级备份配置后关闭这两项。

Edge 单独下载 `Yingche-Edge-v0.6.0.zip`，或使用播放器包内的 `edge-extension`。在 `edge://extensions` 开启开发人员模式、加载该文件夹；旧安装需重新加载扩展并刷新视频页面。视频和照片在本机处理。

网页美颜不必打开播放器：运行 `YingcheService.exe`（映澈后台服务）即可，它常驻通知区域，只提供扩展需要的本地引擎，可设为登录后自动运行。也可以继续在播放器中开启 Edge 连接。详见 [Edge 使用说明](EDGE使用说明.md)。

## 当前限制

这是预发布版本。遮挡、快转头、大侧脸仍可能失去跟踪；手与脸同色时不能保证遮罩完全排除。换脸失跟及补帧果冻变形没有在本轮彻底修复。桌面新美颜/参数/双屏功能不代表网页端同步具备；网页 VSR 与补帧链路沿用上一版，未验证日常 Edge 的 NVIDIA 驱动激活。

保留 SDR 8-bit、内部最大 2560×1440 的链路，4K 屏显示不等于原生 4K 渲染。真实 1080p60 高运动、HDR、物理拔插显示器、全新单屏会话和主观肤质仍待验收。DRM 视频不支持，跨域视频可能需要用户主动捕获。
