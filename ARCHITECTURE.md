# 映澈 0.4.1 architecture

Native: libmpv RGBA8 FBO -> asynchronous face-swap precomposition -> actual GPUPixel BeautyFaceFilter -> local geometry/makeup shader -> Qt QOpenGLWidget. Qt 6.8.3 / C++17 / OpenGL 3.3 compatibility context. GPUPixel executes in the current host context; no extra GLFW window. Host boundaries reset GL state. SDK resource paths accept Unicode.

Web: HTML video -> WebGL2 texture -> same swap precomposition -> upstream GPUPixel compiled with Emscripten 6.0.10 -> project geometry/makeup shader. src/web contains the shared-context C++ adapter. gpupixel.js embeds WASM and four upstream LUT resources locally, with DYNAMIC_EXECUTION=0. gpupixel-build.json records revision/compiler/hash; runtime version comes from compiled C++. ImageBitmap decoding explicitly uses premultiplyAlpha=none and colorSpaceConversion=none because WebGL pixelStore alpha flags do not override ImageBitmap preparation. A known 50% alpha colour pixel regression verifies no double multiplication/dark edges. No remote script, fake shader substitute or silent legacy fallback. Failure keeps original video and reports the error.

GPUPixel 1.3.0 revision 5415b738817553f339620b89ea755bdbfe44e166 supplies skin smoothing, positive whitening and sharpening. Existing host-authored geometry, negative localized brightness, warmth, pink, lips and blush remain distinct. The upstream single-face detector is disabled; tracker handles up to four slots (one/two-face samples tested).

Tracking: max 960x720 input, no upscaling. MediaPipe VIDEO landmarks at least every 30ms, Lucas-Kanade forward/backward flow (25x25, pyramid level 4), robust affine continuation, YuNet/cropped-landmark recovery and periodic discovery. Current detections avoid redundant full reacquisition. Flow-only confirmation is bounded to 120ms. Face IDs follow spatial/flow association; they are not identity recognition. Shader prediction is bounded to 60ms and 1/4 face width. Masks are generated at max 512 resolution with normalized coordinates. Current paused poses do not expire.

Deep-Live-Cam revision d759e31b11d9432afdfddce698c0f7c9a715e086: tools/dlc_core contains unchanged upstream _get_soft_alpha, _fast_paste_back, apply_color_transfer, preprocess_face, postprocess_face, _get_face_affine and enhance_face_onnx function bodies. The host provides headless imports/device sessions; tools/vendor_dlc_core.py reproduces extraction. Upstream source and AGPL license are included. InsightFace 0.7.3 supplies RetinaFace/SCRFD det10g, ArcFace, INSwapper and face alignment. A small NumPy similarity transform replaces the scikit-image dependency; source is included. GPEN-256 restoration is mixed with the original generated face, then color matched and pasted back using DLC functions.

AsyncSwap owns independent ONNX Runtime DirectML sessions on its worker thread. It keeps one latest pending frame, never a FIFO. Result patches retain input affine, landmarks and stable track IDs. The tracking thread estimates a current RANSAC affine over 14 anchors, rejects inconsistent results and feathers within a face ROI; forehead preservation avoids importing source bangs. Results fade at 160-260ms and expire at 260ms. Same paused PTS deduplicates work and does not expire. Seek/source/generation changes invalidate all old results. Source-photo data is not written to disk.

Native IPC: JSON header + bounded raw RGBA, one request in flight. 8ms scheduling checks are not a claimed 125fps inference rate. Request generation, PTS and render serial reject old frames. Seek/start waits for MPV playback restart and refreshed render. Worker failures keep the original video; reselecting a source restarts a failed process.

MV3: activeTab/scripting/storage, loopback-only host permission, stable extension ID. One active enhanced tab; enabling another stops the previous overlay so trackers do not alternate streams. Bridge checks Host, Origin, extension ID and ephemeral token; frame requests cannot read arbitrary local files. Browser and bridge versions must both be 0.4.1. Cross-origin capture uses an explicit browser picker. User Edge profile was not modified by tests.

Build: CMake builds actual vendored GPUPixel with host adapters, then BeautyPlayerV041.exe and a Yingche.exe launcher. PyInstaller packages face_worker.py, tracking, DLC/InsightFace runtime and bridge as app/face_engine_v041/FaceEngine.exe. Browser compilation is tools/build_gpupixel_web.py. Build requirements and corresponding sources are included; toolchains are not shipped. Old releases are preserved.

Portable staging excludes user settings/history, private photos, test browser profiles and old runtimes. Tests using --control-dir isolate settings from normal playback. The public release is staged separately without model weights or local state.

0.4.1 browser playback: reuse a 2D OffscreenCanvas and send JPEG at quality 0.94 (max 960x720, no upscale) through the MV3 bridge. The source video texture remains uncompressed by this transport. Capture PTS/time/generation/config are sampled together before encoding; obsolete completions are discarded. Native IPC stays raw. GPUPixel input caching uses decoded frame count, and rendering is capped around 60Hz. Renderer pose lifetime follows measured transport + update interval, clamped to 220–350ms with an 80ms fade. Paused current poses are stable, seeking invalidates them, and visibility resume reacquires. Actual drawing counts/weight and end-to-end roundtrip are exposed in status.

The Windows loopback listener uses SO_EXCLUSIVEADDRUSE and disables address reuse. Version checking runs on initial connect and automatic session renewal. Tests copy the extension and change only its loopback port to avoid interacting with a running user bridge.

Brief secondary detector misses may reuse a recent swap patch only while the same selected track remains visible, using the original timestamp and the existing 260ms expiry plus current landmark alignment checks. Strong optical flow can reject a landmark jump for at most 120ms without renewing its last confirmed timestamp. This is bounded motion continuation, not an indefinite frozen-face hold.
