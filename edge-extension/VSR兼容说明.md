# 映澈 Edge 扩展 0.4.2 · RTX VSR 兼容实验版

修复方向：GPUPixel/换脸输出经不透明 2D 像素转换，再以视频流显示，恢复进入 Chromium 的 NVIDIA 视频处理链路。兼容模式按照源视频分辨率处理，保留放大给 VSR 完成的机会（内部上限仍为 2560×1440，SDR 8-bit）。

## 使用

1. 在 `edge://extensions` 中，刷新「映澈 · 网页美颜与换脸」，确认版本为 0.4.2。
2. 刷新正在看的视频网站页面，重新点击「启用当前视频」。
3. 勾选「RTX VSR 兼容（实验）」（默认开启）。播放器/本地引擎仍使用 0.4.1。
4. NVIDIA App 中开启超分，并在播放时查看是否变成「已激活」。将视频显示尺寸放大到源分辨率以上进行验证。此次没有修改你的显卡或 Edge 设置。
5. 如果兼容模式导致卡顿，可取消勾选，立即回到原来的 Canvas 输出；「停止增强」恢复网页原播放器。

## 已验证及边界

- 在本机 RTX 5070、隔离 Chromium 153 上测试了实际 GPUPixel、DirectML 换脸与扩展界面。
- 在原视频隐藏的条件下，最终处理视频在 3 秒内有 180 次 `ToggleNvidiaVpSuperResolution(on=true)` 调用。该结果证明浏览器请求了 NVIDIA 超分，不等同于已核实 NVIDIA 驱动最终启用，也不等同于你日常 Edge 网站验收。
- 720p 处理视频显示为 1600×900；最终视频与美颜/换脸渲染结果的平均像素差约 0.25/255；输出没有额外音轨，网页继续负责声音。
- 1 倍、2 倍输出测试均在 2 秒提交 120 帧；进度跳转、回到前台、停止、切换普通/兼容模式通过。提交帧数不是 NVIDIA 最终超分帧率。
- 运动换脸压力测试尚未完全通过旧版 95% 连续有效帧门槛：1 倍约 96.0%，2 倍约 92.4%，有短暂对齐失败和一次延迟尖峰。因此仍标为实验模式，不宣称高倍速换脸已解决。
- 新输出增加像素转换和显示缓冲，可能增加延迟/显卡负载；受保护视频、跨域限制和原有侧脸遮挡限制仍适用。未验收 HDR。
